# Rajveer Singh Pall · AI Research

The research homepage of an AI researcher asking one question across machine
learning evaluation: **do reported results mean what they claim?** Twelve papers
and manuscripts (one published, five under review) are framed as one program,
with benchmark identification as the flagship result.

Live: https://rajveer-research.vercel.app

## Homepage

Hero (with current status and latest news) → three findings → research vision →
**flagship: an interactive MATH-Hard leaderboard** that switches between the
published ranking and the ranking the evidence identifies, with tie bands on hover
or focus → research trajectory → research map (nine themes; a readable list on
phones) → publications with a status filter → research infrastructure → output
counters → open questions → news → about and contact.

## Paper pages: one reading order

Every paper uses the same template (`src/pages/research/[slug].astro`), and a
section appears only when the paper has content for it:

1. Header: status, title, authors, one-line discovery, public links
2. The discovery in one figure: a bespoke SVG per paper (`HeroFigure.astro`)
3. The paper in five minutes
4. The research question
5. How it works: method prose and a step flow
6. Experimental results: data figures, key numbers, stated limitations
7. Figures from the paper, optimized at build time
8. What this changes
9. Resources and citation, including what is not public yet and why
10. Related research, ranked by shared themes

## Content integrity

- `src/data/research.ts` is the single source of truth. Each paper names its source
  file in a comment, and every number traces to that source or the application
  dossier.
- Status vocabulary is strict and never upgraded: Published, Under review, Working
  paper, Manuscript, In preparation. The venue of a double-blind submission under
  review is not named, and private or anonymised repositories are not linked.
- The leaderboard data (`src/data/leaderboard.json`) is regenerated by
  `scripts/build-leaderboard.mjs` from the public flipbudget-results dataset; the
  script asserts that all 378 public pairs reproduce exactly.
- Scholar citation tags are emitted only for published work and public working
  papers.

## Motion and accessibility

GSAP ScrollTrigger with masked kinetic type, Lenis smooth scroll, a site-wide
ambient data field and Astro view transitions. Reveals use
`immediateRender: false` so content is never left hidden, and everything is off
under `prefers-reduced-motion`; readers without JavaScript see all content. The
leaderboard is a keyboard-operable radio group and table (arrow keys, Home, End,
Escape), filters announce their result count, and a skip link leads to the
content.

## Stack

- [Astro 7](https://astro.build): static output, content-driven
- [GSAP 3.13](https://gsap.com): ScrollTrigger, SplitText
- [Lenis 1.3](https://github.com/darkroomengineering/lenis): smooth scroll via `gsap.ticker`
- Self-hosted fonts (Fontsource): Newsreader, Instrument Sans, Fragment Mono
- `sharp`: build-time image optimization, Open Graph image and touch icon

## Develop

```sh
npm install
npm run dev                          # http://localhost:4321
npm run build                        # static build to dist/
npm run preview                      # serve the built output
node scripts/build-leaderboard.mjs   # regenerate src/data/leaderboard.json
node scripts/build-og.mjs            # regenerate public/og.png and apple-touch-icon.png
```

Deploys on Vercel from `main` (framework preset: Astro, output `dist/`). The
sitemap is generated from the paper data at build time (`src/pages/sitemap.xml.ts`).

## Structure

- `src/data/research.ts`: publications, discovery captions, timeline, research
  infrastructure, output counters, news, identity
- `src/data/leaderboard.json`: the flagship leaderboard
- `src/components/`: homepage sections (Hero, Highlights, Flagship with Board,
  ResearchMap, Publications, OpenScience, News, Contact, …) and paper-page parts
  (HeroFigure, FigureBars, MethodFlow, PaperFigures)
- `src/pages/research/[slug].astro`: the shared paper template (12 papers)
- `src/assets/figures/<slug>/`: real publication figures
- `src/styles/tokens.css`: design tokens ("Laboratory Paper": colour, type, spacing, motion)
- `src/scripts/motion.ts`: GSAP and Lenis wiring, reduced-motion safe
- `RESEARCH.md`: original design and technology rationale
